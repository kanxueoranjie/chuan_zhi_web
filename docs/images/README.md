# 截图清单

把下面 6 张图截好放进这个目录（`docs/images/`），README 里的图片就会自动显示。

## 命名要求（必须一致）

| 文件名 | 截哪个页面 | 怎么截 |
|---|---|---|
| `01-login.png` | `http://127.0.0.1:5000/login` | 打开登录页，直接截 |
| `02-dashboard.png` | 登录后跳到的 `/` | **用 `only_user` 登录**，能看到 4 个功能入口 |
| `03-funds.png` | `/class_funds` | 等 AI 分析出来再截（第一次要等 5~10 秒） |
| `04-leave.png` | `/six_day` | 学号姓名是灰底只读，能看到拖拽上传区 |
| `05-console.png` | `/only_user` | 左侧 5 个菜单 + 右侧班级详情统计卡 |
| `06-assistant.png` | 任意页面 | **先点右下角助教，问一句「班费还剩多少」，等它答完再截** |

## 截图技巧

1. **用 Chrome，窗口拉到 1400px 宽左右**，画面最舒展
2. **截整页**（含滚动部分）：
   ```
   F12 → Ctrl + Shift + P → 输入 screenshot → 选 "Capture full size screenshot"
   ```
3. **助教那张最关键** —— 要截到对话内容，能体现"AI 真的在读数据库"
4. 图片不要太大，单张控制在 500KB 以内，避免仓库变臃肿
